Connectez-vous avec votre compte Discord, ou liez-le à votre compte Reflect FiveM, et suivez le crédit que vous rapporte le tag du serveur Reflect.

## Nouveautés

- **Continuer avec Discord** : sur la page « Compte », connectez-vous avec Discord comme avec Google. Si l'application Discord est ouverte sur votre PC, l'autorisation s'y affiche directement, sinon la page de Discord s'ouvre dans votre navigateur. Si aucun compte n'a l'adresse e-mail de votre compte Discord, un compte est créé pour vous.
- **Comptes liés** : depuis votre profil, liez votre compte Discord à votre compte pour vous connecter avec lui ensuite. Sa photo, son nom et votre identifiant Discord (@nom) s'affichent ; « Retirer » défait la liaison.
- **Tag du serveur Reflect** : affichez le tag du serveur Discord Reflect sur votre profil Discord pendant 4 jours cumulés pour gagner un crédit « Créer ton pack ». Sous votre compte Discord lié, voyez si le tag est affiché, le temps qui manque avant le crédit, puis le crédit obtenu ; un bouton vous fait rejoindre le serveur Discord. Ensuite, le temps avec le tag est encore compté, seulement pour que vous voyiez combien de temps vous l'avez porté. Le temps passé avec le tag avant la liaison compte aussi : le crédit vous est donné dès que vous liez votre compte Discord.

## Améliorations

- Un refus sur la page de Discord, une connexion Discord indisponible ou un échec ont chacun leur message, dans le navigateur comme dans l'application.
